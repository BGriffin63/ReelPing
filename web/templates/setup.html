Welcome — let's get you set up

ReelPing watches your media server and keeps your Discord community informed. This runs once.

1. Administrator account

There is no default username or password. Create your admin login now.

2. Plex server connection

Enter the network address ReelPing should use to reach Plex. Plex may run in Docker, a VM, another NAS, or another server — ReelPing only needs a URL it can reach.

3. Discord

ReelPing uses a Discord incoming webhook (no bot required). Paste your channel's webhook URL.

4. Monitoring

Custom thresholds (only used with the Custom preset)

With Balanced defaults, an outage is confirmed in about one minute (interval × failure threshold).
